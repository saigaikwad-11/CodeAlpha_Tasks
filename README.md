## 🎮 Task 1: Beach Safari Hangman Game

An interactive 2D Hangman game built using Python and Pygame with custom backend logic and interactive visual elements.

### ✨ Features
* **Custom Themes:** Beach Safari visual layout with interactive graphical elements.
* **Gameplay Mechanics:** Dynamic attempt tracking, category selection, and live hint system.
* **Audio & Effects:** Smooth keyboard inputs, win/loss visual indicators, and score tracking.

### 🛠️ Tech Stack
* Python 3.x
* Pygame

### 🏃 How to Run
cd Task1_HangmanGame
python3 Beach_Safari_Hangman.py

## 📈 Task 2: Stock Portfolio Tracker Dashboard

An interactive corporate financial dashboard built using Python, Streamlit, and Plotly to track real-time stock market asset allocations and performance.

### ✨ Features
* **Live Market Assets:** Tracks assets like TITAN, RELIANCE, TATA MOTORS, etc.
* **Visual Analytics:** Interactive Plotly donut charts showing real-time investment gains and losses.
* **Portfolio Metrics:** Dynamic balance updates, asset breakdown, and requirements tracking.

### 🛠️ Tech Stack
* Python 3.x
* Streamlit
* Plotly, Pandas, yfinance

### 🏃 How to Run
cd Task2_StockPortfolioTracker
pip install -r requirements.txt
python3 -m streamlit run StockPortfolioTracker.py

## 🤖 Task 3: Interactive Chatbot Application

An interactive chatbot application developed using Python and Streamlit with session state management, theme switching, and response handling.

### ✨ Features
* **Multi-Theme UI:** Support for dark/light themes and customizable layouts.
* **Session Persistence:** Remembers user chat history, recent conversations, and ratings across sessions.
* **Smart Processing:** Structured responses with rule-based and conversational processing.

### 🛠️ Tech Stack
* Python 3.x
* Streamlit

### 🏃 How to Run
cd Task3_Chatbot
python3 -m streamlit run Chatbot.py
